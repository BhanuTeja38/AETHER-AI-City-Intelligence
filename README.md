## 🎯 Problem Statement & Civic Need

Modern metropolitan areas face cascading urban crises where one localized disruption rapidly compounds another:
- **Hydrological Inundation:** Heavy rainfall inundates stormwater canals, cresting embankments and flooding lowlands.
- **Arterial Gridlock:** Flooded or blocked roads push excess traffic onto secondary transit corridors, creating gridlock that hinders emergency services.
- **Sensor Blindness:** Traditional cities operate with fragmented sensor silos that lack unified risk aggregation.
- **Delayed Response:** Manual cross-agency triage wastes vital minutes during the golden hour of crisis mitigation.

**The Solution:** AETHER provides a single unified pane of glass combining real-time spatial visualization, live simulated IoT telemetry, dynamic scenario stress-testing, and automated AI contingency synthesis.

## 🚀 Key Features

### 1. Overview Command Dashboard
- **Real-Time KPIs:** Live tracking of Active Incidents, Flood Risk Zones, Traffic Congestion %, Road Blockages, Connected IoT Fleet, and City Composite Risk Score (0–100).
- **Responsive Dynamic Charts (Recharts):**
  - City Multi-Vector Risk Trends (time-series area projections)
  - Incidents by Urban Vector (Flood, Traffic, Road Blockage, Emergency)
  - Severity Distribution Breakdown (Critical, High, Moderate, Low)
  - IoT Sensor Network Fleet Health indicator
- **Emergency Dispatch Ticker:** Synchronous radio dispatch feeds and telemetry logs updated in real-time.

### 2. Interactive Geo-Spatial City Map
- **Leaflet & CartoDB Dark Matter Engine:** Ultra-smooth, dark cyber styling with fluid panning, zooming, and zero blank tile artifacts.
- **Interactive Layers & Toggles:**
  - 💧 **Flood Risk Zones:** Dynamic SVG radius circles representing flood water expansion.
  - 🚗 **Traffic Congestion:** Color-coded saturation corridors.
  - ⛔ **Road Blockages:** Infrastructure hazards with automated detour paths.
  - 🔥 **Emergency HazMat:** Containment cordons and evacuation polygon perimeters.
  - 📡 **IoT Sensor Grid:** Live interactive sensor pins with threshold indicators.
  - 🟢 **Smart Detour Corridors:** Animated arterial rerouting lines.
- **Slide-Up Telemetry Inspector:** Click any incident or sensor on the map to inspect real-time metrics, update incident statuses, or deploy protocols directly.

### 3. Incident Management Center
- **Tabular & Card View Layouts:** Switch seamlessly between a high-density operations table and rich metric cards.
- **Multi-Vector Filtering & Search:** Filter by category, severity (Critical to Low), status (Open, Investigating, Responding, Resolved), or search by keyword and location.
- **Live Status Control:** Transition incidents through Open ➔ Investigating ➔ Responding ➔ Resolved, accompanied by celebratory resolution feedback.
- **Report / Inject Incident Modal:** Allows evaluators to create and dispatch custom incidents into the live simulation.

### 4. IoT Sensor Monitoring Fleet
- **Simulated 24-Node LPWAN Mesh:**
  1. *Water-Level Sensors (meters)* – Embankments, sluice gates, and tidal basins.
  2. *Rainfall Pluviometers (mm/h)* – Downtown rooftops, weather masts, and port stations.
  3. *Traffic Density Radars (% saturation)* – Viaduct ramps, bridges, and commercial avenues.
  4. *Road Blockage & Tilt Sentinels* – Acoustic tunnel strain, flyover clearance, and utility tilt.
  5. *Emergency Optical / Acoustic Pods* – Transformer thermal hotspots, VOC particulate AQI, and acoustic triangulation.
- **Dynamic Telemetry Stream:** Readings organically fluctuate with simulated urban physics and spike during active crisis scenarios.
- **Historical Sparklines & Modal:** Click any sensor to inspect a 10-cycle telemetry area chart and calibration specifications.

### 5. AI City Intelligence Engine
- **Prominent "Analyze City" Control:** Triggers multi-stage neural diagnostic synthesis:
  1. Ingesting IoT telemetry streams & spatial vectors
  2. Cross-referencing civil bottlenecks & incident clusters
  3. Computing multi-agency dispatch & traffic diversion topologies
  4. Synthesizing executive directives
- **Mathematical Derivation & Radar Chart:** Breaks down weighted risk factors:
  - *Hydrological & Environmental Hazard (35% weight)*
  - *Urban Mobility & Gridlock Factor (25% weight)*
  - *Critical Infrastructure & Fire Hazard (25% weight)*
  - *IoT Sensor Mesh Health (15% weight)*
- **Incident-Specific AI Triage:** Select any incident to generate a bespoke AI contingency response plan.
- **Actionable Directives:** "Deploy Protocol" buttons execute automated field orders with real-time status updates.

### 6. Dynamic Scenario Simulation Studio
- **4 Built-in Crisis Scenarios:**
  1. 🌊 **Urban Flood & Storm Surge:** Simulates 60+ mm/h rainfall, rising canal levels, sluice gate alerts, and lowland detours.
  2. 🚗 **Rush Hour Gridlock:** Escalates viaduct saturation to 95%+, triggers green-wave traffic signal retiming, and opens highway bypasses.
  3. ⛔ **Road Blockage & Structural Hazard:** Simulates tunnel spalling and debris collapse with acoustic sensor triggers.
  4. 🔥 **Industrial HazMat & Substation Blaze:** Simulates thermal hotspots (165°C), toxic VOC smoke drift, and a 500m evacuation cordon.
- **Controls:** Play, Pause, Resume, Reset Baseline, and Speed multipliers (1x, 2x, 5x).
- **Phased Event Log:** Dynamic radio transmissions from patrol units and autonomous telemetry relays.

### 7. Executive Reports & CSV Export
- Complete audit trail of all recorded civic emergencies.
- 24-hour historical risk trajectory chart.
- Incident recovery throughput (Active vs. Resolved).
- **1-Click CSV Export:** Generates an official, comma-separated dataset download instantly in the browser without third-party services.
- **Printable Executive Briefing View:** Formatted for high-level civic stakeholder reporting.

## 🧪 Simulation Physics & AI Model

### Simulated IoT Demonstrator
AETHER includes realistic mathematical noise and correlation algorithms:
- Every 2 seconds (divided by the speed multiplier), sensors drift organically within nominal operating tolerances.
- When an active scenario is engaged, correlated sensor groups experience compounding scalar increases.
- If a sensor's `currentReading` surpasses its `warningThreshold`, its status flips to **Warning**, illuminating an ambient amber pulse and generating an alert notification.
- *Notice:* The system is purposefully engineered to operate 100% offline with zero paid API keys, while exposing standard TypeScript interfaces ready for physical MQTT, REST, or CoAP edge-gateway integration.

### Local Rule-Based AI Engine
The AI City Intelligence Engine computes composite threat scores using a deterministic weighted matrix:
$$\text{Risk Score} = 30 + (\text{Active Incident Weight}) + (\text{Sensor Warning Penalties}) + (\text{Scenario Strain})$$
- Scores $\ge 80$: **Critical** (Red ambient alert)
- Scores $60 - 79$: **High** (Amber ambient alert)
- Scores $40 - 59$: **Moderate** (Yellow ambient alert)
- Scores $< 40$: **Low** (Cyan nominal baseline)

## 💻 Setup & Installation Instructions

Follow these exact steps to run the application from a fresh clone:

### Prerequisites
- **Node.js**: v18.0.0 or higher (v22+ tested and recommended)
- **npm**: v9.0.0 or higher

### Installation Commands

```bash
# 1. Clone repository (or navigate to project folder)
cd aether-city-intelligence

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

The application will be live at:
```
http://localhost:3000
```
*(or the local port displayed in your terminal, e.g. http://localhost:5173)*

### Building for Production

To create an optimized production build:
```bash
npm run build
```
To preview the built production bundle:
```bash
npm run preview
```
